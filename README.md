# Сайт компании медицинской диагностики
### Данный сайт предназначен для предоставления пользователям возможности самостоятельно оценить состояние своего здоровья путем прохождения онлайн-диагностики. Система помогает выявить возможные проблемы со здоровьем и рекомендует обратиться к врачу для дальнейшего обследования.

## Функционал системы
### - Регистрация новых пациентов: создание профилей пациентов с указанием основных данных (ФИО, контактная информация).
### - История болезни: ведение записей о состоянии здоровья каждого пациента, включая диагнозы, процедуры и рекомендации врача.
### - Расписание приемов: управление графиком приема пациентов, запись на прием.

## Установка и запуск
### Для установки и запуска системы выполните следующие шаги:
- Убедитесь, что у вас установлен python 3.11 или более новая версия
- Убедитесь, что у вас установлен PostgreSQL и запущен локальный сервер для базы данных
- git clone https://github.com/inessa220/medical.git
- Установите зависимости командой `pip install -r requirements.txt`
- В файле .env.sample заполните данные для работы с проектом и переименовать его в .env
